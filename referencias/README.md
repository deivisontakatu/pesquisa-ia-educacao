# Referências

Espaço para referências bibliográficas consolidadas do projeto.

## Arquivos sugeridos

- `referencias.bib` — BibTeX
- `referencias.ris` — RIS
- `referencias.md` — lista legível em Markdown

## Regra

Sempre que uma referência for adicionada, preservar pelo menos:

**autores, ano, título, periódico/evento, volume/número quando aplicável, DOI e URL.**
