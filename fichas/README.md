# Fichas de leitura

Esta pasta concentra as **análises estruturadas dos artigos**, permitindo comparar estudos sem precisar reler todos os PDFs durante a escrita de um novo trabalho.

## Modelo mínimo

- Referência bibliográfica
- DOI/URL
- Objetivo
- Problema
- Questão de pesquisa
- Fundamentação teórica
- Metodologia
- Amostra/contexto
- Tecnologia de IA
- Variáveis ou construtos
- Resultados
- Limitações
- Lacunas
- Contribuições
- Palavras-chave
- Trechos/citações relevantes
- Relação com pesquisas futuras

## Convenção de nomes

`ANO-AUTOR-TEMA.md`

Exemplo:

`2025-Qian-aplicacoes-pedagogicas-genai.md`
